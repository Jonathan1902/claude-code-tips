O que cada campo significa

Leia da esquerda para a direita

Modelo ativo Qual Claude está respondendo agora — Opus, Sonnet ou Haiku. Mude com --model ou CLAUDE.md.
Tokens na sessão Total de tokens de entrada + saída acumulados. Perto do limite? Compacte o contexto com /compact.
Custo em USD Custo real da sessão. O campo mais usado por squads de tecnologia financeira para controlar gasto por tipo de tarefa — relatório, refatoração, revisão.
Modo de permissão auto pede confirmação; bypassPermissions age direto. Visível para não esquecer em qual modo você está.

Como ajustar o que aparece

Personalize via settings.json ou linha de comando

# Trocar o modelo exibido na statusline: claude --model claude-opus-4-5 # Ou na sessão aberta, sem reiniciar: /model
# Forçar modo manual (fica visível na statusline): claude --permission-mode manual # Desativar custo (útil em demos e capturas de tela): # settings.json → "showCost": false
  • O campo de modelo muda imediatamente ao trocar com --model ou via /model na sessão
  • Em ambientes regulados (compliance), ative o modo manual para deixar explícito que nenhuma ação roda sem aprovação
  • Equipes de compliance podem padronizar o modo manual no CLAUDE.md do projeto — garante consistência entre todos os devs do time
