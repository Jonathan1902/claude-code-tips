Claude Code em uma frase

"Um agente de IA que lê, escreve e executa código direto no seu terminal — sem copiar e colar."
  • Acessa arquivos, roda comandos e lê erros do terminal
  • Trabalha no seu projeto real, não num sandbox isolado
  • Você aprova cada ação antes de executar

Três formas de usar Claude

Cada uma serve a um perfil diferente

💬 Chat Web (claude.ai) Conversa no browser. Sem acesso ao seu código local.
🔌 API Anthropic Você constrói a integração. Máximo controle, máximo esforço.
⚡ Claude Code Agente pronto no terminal. Acessa seu repo, roda comandos, itera.

Claude Code resolve o seu caso?

  • Resolve: refatoração, debugging, geração de testes, automação de CLI, code review
  • Resolve: tarefas repetitivas que exigem editar múltiplos arquivos ao mesmo tempo
  • Não resolve: geração de imagens, análise de dados sem código, respostas a perguntas gerais
  • Não resolve: tarefas que não envolvem um repositório ou arquivos locais

Três frases para fixar o conceito

  • Claude Code é um agente de terminal, não um chatbot
  • Diferente do Chat Web: ele age no seu repo local, sem copiar e colar
  • Se o seu trabalho envolve código → vale testar hoje
