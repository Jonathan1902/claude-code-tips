Configure o CLAUDE.md

O arquivo que transforma o agente em um colega que conhece seu projeto

  • Descreva a stack, arquitetura e padrões de código do projeto
  • Documente restrições de compliance — o agente saberá o que nunca tocar
  • Adicione comandos e fluxos frequentes como referência rápida
  • Defina o que o agente pode e não pode alterar no codebase
# CLAUDE.md — sistema de risco Stack: Python + FastAPI + PostgreSQL Nunca modificar: /legacy/*, /migrations/*, /audit-logs/* Compliance: toda alteração em cálculo de VaR exige revisão manual

Comece com /init

O Claude varre o repositório e gera um CLAUDE.md inicial para você

  • Execute /init dentro do Claude Code — funciona em projetos novos e em legados sem documentação
  • O arquivo gerado é um ponto de partida, não uma versão final — revise antes de commitar
  • Acrescente contexto que o agente não consegue inferir só lendo o código: decisões de arquitetura, restrições regulatórias, acordos de equipe
# no terminal, dentro do projeto $ claude > /init # Claude analisa o codebase e cria o CLAUDE.md # Revise, ajuste e faça o commit junto com o código

Trate como código, não como README

Um CLAUDE.md desatualizado é pior do que nenhum

  • Commite junto com o PR que muda stack, arquitetura ou padrões — o contexto evolui com o código
  • Revise a cada marco importante: novo módulo, mudança de biblioteca, entrada de regulação
  • Registre a data da última revisão no topo do arquivo — sinaliza para a equipe quando está ficando defasado
# CLAUDE.md — sistema de risco # Última revisão: 2025-06 (migração para FastAPI 0.115) Stack: Python + FastAPI + PostgreSQL

Múltiplos níveis para codebases complexos

O Claude lê todos os CLAUDE.md do caminho — do mais geral ao mais específico

  • Raiz do repositório — regras globais: stack, padrões de commit, restrições de compliance
  • Pasta de módulo — regras específicas daquela área, sem poluir o contexto global
  • .claude/ — comandos customizados, hooks e permissões de agente
projeto/ ├── CLAUDE.md # regras globais ├── risco/ │ └── CLAUDE.md # regras do módulo de risco └── relatorios/ └── CLAUDE.md # relatórios regulatórios
