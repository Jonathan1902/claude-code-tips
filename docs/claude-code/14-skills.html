O que são Skills?

.claude/ └── skills/ └── gera-relatorio/ └── SKILL.md ← instrução da skill
  • Você digita /gera-relatorio e o agente produz o relatório de posições — sem redigitar nada.
  • Skills são mini-roteiros que ensinam o agente a executar uma tarefa específica do seu jeito — basta invocar com /nome-da-skill
  • Ficam versionadas no repo — todo o time acessa as mesmas automações
  • Uma skill bem escrita elimina 5–10 minutos de prompt repetitivo por tarefa — multiplicado pelo time todo.

Anatomia de um SKILL.md

# gera-relatorio ## Objetivo Gerar relatório de posições em Markdown a partir dos dados de `posicoes.csv`. ## Passos 1. Leia `posicoes.csv` 2. Calcule PnL por ativo 3. Grave em `relatorio-YYYY-MM-DD.md`
  • Inclua o contexto necessário: arquivos de entrada, formatos de saída, regras de negócio
  • Quanto mais específico o SKILL.md, mais previsível o resultado
  • Escreva em Markdown simples — o agente lê e segue como se fosse um briefing

Skills vs outras abordagens

Cada opção serve a um perfil diferente

📋 Prompt manual no chat Você redigita as instruções toda vez. Não é versionado e não compartilha com o time.
🔧 Script de shell / Python Automação rígida. Não adapta ao contexto e exige manutenção quando o fluxo muda.
⚡ Skill com SKILL.md Instrução em linguagem natural, versionada no repo. O agente adapta ao contexto do projeto.

Skills resolvem o seu caso?

  • Resolve: gerar rascunho de relatório de risco toda manhã com /gera-relatorio
  • Resolve: padronizar review de PRs com /code-review seguindo checklist de compliance
  • Não resolve: tarefas únicas e espontâneas — um prompt direto no chat é mais rápido
  • Não resolve: automações que precisam rodar sem intervenção humana — use hooks ou CI/CD

O que você leva daqui

Próximo passo: crie .claude/skills/minha-skill/SKILL.md com 3 linhas descrevendo uma tarefa que você repete.

  • Skills = SKILL.md em .claude/skills/nome/ — Markdown simples, sem código
  • Invoque com /nome-da-skill e o agente executa o roteiro automaticamente
  • Versione no repo — toda nova skill vira padrão do time sem treinamento extra.
