Configure hooks para automatizar guardrails

# .claude/settings.json { "hooks": { "PreToolUse": [{ "matcher": "Bash", "hooks": [{"type": "command", "command": "bash .claude/guardrails.sh"}] }], "Stop": [{ "hooks": [{"type": "command", "command": "python notify_slack.py"}] }] } }
  • Hooks disparam comandos shell em resposta a eventos do agente
  • PreToolUse roda antes de cada ferramenta — bloqueia ações indesejadas
  • PostToolUse roda após a ferramenta — ideal para logs e auditorias
  • Stop roda quando o agente termina — notificações e relatórios automáticos

Hooks em uma frase

Hook = evento + matcher + comando shell # Ex.: em todo uso da ferramenta Bash, # rode o script de guardrail antes de executar
  • São configurados em settings.json — versionados junto com o projeto
  • Recebem o contexto via stdin JSON — ex.: {"tool":"Bash","input":{"command":"rm -rf /tmp/prod"}} — ferramenta, parâmetros e resultado
  • Se saírem com código != 0, podem bloquear ou interromper a ação do agente

Os quatro eventos principais

Cada um cobre uma etapa diferente do ciclo do agente

PreToolUse Antes da ferramenta rodar. Use para validar, bloquear ou logar a intenção.
PostToolUse Após a ferramenta completar. Use para auditar, formatar output ou disparar pipelines.
Stop Quando o agente encerra a tarefa. Use para notificações, relatórios e métricas.
Notification Quando o agente emite uma mensagem de usuário. Use para roteamento e alertas.

Hooks resolvem o seu caso?

  • Resolve: impedir que o agente edite arquivos de configuração de produção (PreToolUse + matcher "Write")
  • Resolve: enviar mensagem no Slack ao fim de cada geração de relatório regulatório (Stop)
  • Não resolve: lógica de negócio complexa — hooks são scripts leves, não substitutos de testes
  • Não resolve: aprovação humana interativa em cada passo — use o modo Plan para isso

# PostToolUse → auditoria em audit.log jq -r '[.tool, .input.file_path, now | todate] | @tsv' >> ~/.claude/audit.log
  • Auditoria: PostToolUse loga cada arquivo editado em audit.log com timestamp e usuário
  • Compliance: PreToolUse bloqueia escrita em diretórios de dados sensíveis (PII, carteiras)
  • Notificação: Stop dispara alerta no Teams quando geração de relatório BACEN é concluída
