O que são Subagents?

Claude Code pode delegar partes do trabalho para agentes filhos

  • Subagents são instâncias separadas do Claude que rodam tarefas específicas sob comando do agente principal
  • O agente principal coordena; os subagents executam — cada um com seu próprio contexto isolado
  • Tarefas independentes rodam em paralelo, reduzindo o tempo total de execução
  • Para ativar, basta pedir ao Claude que trabalhe em X e Y ao mesmo tempo — ele usa a ferramenta Task automaticamente
"Compare as carteiras de crédito dos fundos A, B e C em paralelo e sinalize as inconsistências de provisão."

A ferramenta Task por dentro

Como o Claude Code spawna subagents na prática

[ Orquestrador ] — recebe o prompt e define as tarefas ├── [ Subagent A ] — analisa fundo A ├── [ Subagent B ] — analisa fundo B └── [ Subagent C ] — analisa fundo C [ Consolidação ] — orquestrador recebe os 3 resultados e entrega a resposta final
  • Cada subagent recebe um prompt isolado — sem acesso ao histórico completo do orquestrador
  • Resultados são retornados ao agente principal, que consolida e decide o próximo passo
  • O paralelismo é gerenciado automaticamente — sem configuração extra do usuário

O que você leva daqui

Três pontos que você já pode aplicar amanhã

  • Isole o contexto: delegue cada tarefa a um subagent para evitar que estados diferentes se misturem
  • Ative o paralelismo: peça ao Claude para trabalhar em X e Y ao mesmo tempo — ele usa a ferramenta Task automaticamente
  • Escolha o momento certo: use subagents para tarefas independentes e demoradas; mantenha em linha quando os passos forem sequenciais
  • Reflita: qual tarefa do seu dia a dia poderia ser dividida em partes independentes para rodar em paralelo?
